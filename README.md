# ⚡ PokéDex App

<em>A dynamic Pokédex web application built as part of Developer Academy — focused on Vanilla JavaScript, API integration, dynamic rendering, and interactive Pokémon data.</em>

---

## 💡 The Idea

This project was built as a **hands-on exercise** to strengthen my JavaScript skills by developing an interactive Pokédex application using the PokéAPI.

The main focus was on **API integration**, **dynamic content rendering**, **data handling**, and **interactive UI functionality** without using a JavaScript framework.

- Dynamically generated Pokémon cards fetched from the PokéAPI
- Search Pokémon by name or Pokédex number
- Filter Pokémon by type
- Load more Pokémon in batches
- Detailed Pokémon information in an interactive dialog
- Evolution chains, abilities, and level-up moves
- Pokémon cries and type-based card backgrounds
- Visual height comparison between a Pokémon and a 1.7 m trainer

---

## ⚡ Key Highlights

- **API integration** – Pokémon data is fetched dynamically from the PokéAPI
- **Dynamic rendering** – Pokémon cards and detail views are generated using JavaScript template functions
- **Search functionality** – Search Pokémon by name or Pokédex number, with a minimum of three characters
- **Type filtering** – Filter the Pokémon list by their elemental types
- **Load More functionality** – Load additional Pokémon in batches instead of requesting the entire Pokédex at once
- **Detailed Pokémon view** – Explore stats, abilities, type relations, evolution chains, and level-up moves
- **Previous / Next navigation** – Navigate between Pokémon directly inside the detail dialog
- **Pokémon cries** – Play the selected Pokémon's cry
- **Height comparison** – Compare Pokémon sizes against a 1.7 m trainer using a logarithmic scale
- **Reusable templates** – Separate template functions keep HTML generation apart from application logic
- **Modular JavaScript structure** – API requests, templates, styling helpers, and application logic are organized into separate files
